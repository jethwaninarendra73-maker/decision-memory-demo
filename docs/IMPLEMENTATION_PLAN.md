## Assumptions

- Python 3.11+ (developed on 3.15.2, installed 12 Nov 2026).
- Single-user local app; demo roles are selected in the UI and are not authentication.
- All data is fictional and generated by fixtures in `data/fixtures/`.
- Scenario numbers are deterministic illustrations from editable assumptions, not forecasts.
- `requirements.txt` with pinned minimum versions is enough; no `pyproject.toml` unless packaging becomes necessary.

## Risks

| Risk | Mitigation |
|------|------------|
| Python 3.15 is very new; a package may lag behind it | All Stage 01 packages installed and tested on 3.15.2; fall back to 3.14 if a later dependency breaks |
| Scope creep into real connectors or ML | `CLAUDE.md` scope rules; reviewer rejects out-of-scope diffs |
| Permission leaks through graph labels or citations | Filter at repository layer before retrieval (Stage 03); regression tests in Stage 13 |
| Hard-coded headline numbers | Stage 08 tests change inputs and assert recomputation |
| Plotly network rendering is fragile | Table fallback required in Stage 05 |
| Live demo failure | Reset script, offline default, recorded backup run (Stage 14) |
